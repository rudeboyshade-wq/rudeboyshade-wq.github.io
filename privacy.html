Privacy Policy - Scarf

Effective date: September 23, 2026

Scarf accesses only the developer's own TikTok account data, through TikTok's official Login Kit, limited to basic profile and stats information (follower count, following count, video count).

This data is used only to display the developer's own statistics inside a personal assistant application running on the developer's own device. No data is shared with, sold to, or made accessible to any third party. No data belonging to any other TikTok user is collected.

Data is not stored on any external server beyond what TikTok's own API requires to serve the request. Access can be revoked at any time from TikTok's account settings, under connected apps.

Questions about this app can be sent to rudeboyshade@gmail.com.
